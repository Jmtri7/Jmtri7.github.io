# Jmtri7.github.io

My main page: https://jmtri7.github.io/

## Structure

```
index.html            Page markup
css/styles.css         Styles (Editorial Dark theme)
js/projects-data.js    Project card content (data only)
js/render.js           Renders project cards and video into the page
assets/                Media files
```

To add a project card, add an entry to the `projects` array in `js/projects-data.js`.
