# Jmtri7.github.io

My main page: https://jmtri7.github.io/

## Structure

```
index.html        Page markup
css/styles.css     Styles
js/posts-data.js   Post content (data only)
js/render.js       Renders posts into the page
assets/            Media files
```

To add a new post, add an entry to the `posts` array in `js/posts-data.js`.
